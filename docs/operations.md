# Operations Runbook

## SLO

健康检查 99.9%；小于 16 MiB 元数据校验 p95 < 200ms；路由队列恢复时间目标 5 分钟。像素内容不写日志，审计导出只允许受控运维身份。

## 故障演练

停止目标适配器时模拟发送器返回错误，作业转为 `retrying`，第三次尝试后进入 `dead_letter`；恢复适配器后人工重新排队。删除对象文件时索引仍可查询，但重新取像返回明确存储错误，不伪造成功。

## 威胁模型

攻击者可能提交巨大长度、递归序列、恶意 UID 或异常 Pixel Data。解析器使用文件/元素/分片上限、严格长度检查和只允许 Pixel Data 未定义长度。患者字段不进入结构化日志，去标识化映射只在内存端口保存。
